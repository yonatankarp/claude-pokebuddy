# Changelog

## 1.0.0

First public release.

- A Gen 1 Pokémon above your Claude Code prompt, rolled once per machine, with shinies and rare legendaries.
- EXP from prompts, tool use, commits, pushes and PRs, fixed checks, a daily Rare Candy and a per-session score.
- Level, stone and trade evolutions, with the stones earned from coding milestones.
- A speech bubble that reacts to each turn, with a facts-only privacy setting and `/buddy quiet`.
- Save export and import, a backup slot, restore, and a guarded once-a-day reset.
